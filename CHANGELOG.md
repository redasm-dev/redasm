# Changelog

## [v4.0.0-beta4](https://github.com/redasm-dev/redasm/releases/tag/v4.0.0-beta4) - 2026-11-24

### GUI
- Added loader options in Loader selection dialog.
- Added Base Address field in Loader selection dialog.
- Added rebase dialog.
- Added callgraph dialog.
- Added bundle name on MacOS.
- Added "toggle logo" settings for screenshots.
- Added callgraphs in Graphs Dialog (for developers).
- Added xrefs editor dialog.
- Implemented offset based Goto ([#9](https://github.com/redasm-dev/bugs/issues/9)).
- Implemented double click to toggle selections in Analyzers dialog.
- Redesigned FLC dialog.
- Reworked menu bar and application-wide actions.
- Segments dialog now shows banking information (if available).
- Updated light and dark themes.
- **Fixed**: Graph views reset selected node when clicking outside.
- **Fixed**: Selected Graph Node Z-order.
- **Fixed**: 64-bit integers conversion.
- **Fixed**: About dialog commands' formatting.
- **Fixed**: Duplicated actions keys sequence.
- **Fixed**: Icon colors with dark theme.

### Core
- Implemented callgraph API.
- Implemented `RDHash`.
- Implemented HTTP and Socket API sets, opt-in, OFF by default.
- Implemented loader options (via `RDLoaderPlugin.get_options`).
- Implemented `rd_reader_open`, `rd_reader_open_data`, `rd_reader_close`, `rd_kb_get_paths`, `rd_renderer_fmt`.
- Implemented `rd_is_offset`, `rd_scratch_resize`, `rd_net_is_supported`, `rd_get_callees`, `rd_get_callers`.
- Implemented `RDFunctionGraph` API set.
- Unified ALU operations (for processor plugin developers).
- Unified register description implementation (for processor plugin developers).
- Introduced `RDPlatformPlugin`.
- Added `.shutdown` in `RDModuleDescriptor` (optional, executed while are still loaded).
- Added `SHA` and `ADLER32` hashing algorithms.
- Added ULEB128/SLEB128 reader APIs.
- Added `rd_settings_` API set (user config for plugins, when needed).
- Added `ego` and `radial` graph layouts.
- Added branch table support.
- Improved autonaming & added array autonaming support.
- Improved array rendering.
- Improved type and nested types rendering.
- Redesigned undefine logic.
- Reworked type resolver (type-to-field path recovery, field offset calculation, etc).
- Reworked `byteorder.h`.
- Reworked and exposed filesystem's Path APIs.
- Splitted layout and renderer logic.
- Splitted processor selection and setup phases.
- Lazy initialize interned string table.
- CFG nodes are now address-ordered.
- Cleaned and refactored core engine "tick" logic.
- Improved `SurfaceGraphView` behavior and UX.
- Renderer now allows explicit base radix.
- Graphs renders address and function lines.
- XRefs are now sorted by address.
- RDSettings/RDDatum concept split.
- `rd_find_function` => `rd_function_find`.
- `rd_find_segment` => `rd_segment_find`.
- `rd_disassemble` => `rd_run`.
- **BREAKING**: Implemented address rebase.
- **BREAKING**: `rd_kbobject_` replaced with `rd_datum_` APIs.
- **BREAKING**: Reworked problem storage and `RDProblem` struct.
- **BREAKING**: Reworked and simplified function API and internal storage.
- **Fixed**: Shared function basic blocks and tail calls.
- **Fixed**: Address calculation for autogenerated names.
- **Fixed**: `rd_get_address` now allows `NULL` argument.
- **Fixed**: `rd_renderer_str` background color.
- **Fixed**: Skip already registered KB types.
- **Fixed**: Hardcoded `abi.h` installation path.
- **Fixed**: Don't try to load settings file if doesn't exists.

### Processors
- Android Dalvik.
- SM83.
- Improved cross referencing behavior on ARM.
- **BREAKING**: MIPS moved to Capstone backend (COP2 instructions are custom decoded and hooked for platform plugins).
- **Fixed**: MOS6502 decoding and register width.

### Loaders
- Android Dex.
- GameBoy, GameBoy Color, GameBoy Advance.
- Added `wide_scan` option to PE loader (off = auto guessed).
- All loaders now uses `rd_reader_read_exact` instead of `rd_reader_read` for stricter validation.
- PSX bios calls now relies on MIPS instruction shape rather than RDIL emulation.
- **BREAKING**: PE now notifies core about image base, segments are now RVA addressed.
- **Fixed**: PE now uses its internal module name for exported functions (if available).
- **Fixed**: Don't initialize $sp register for PSX executables.

### Analyzers
- PDB v7 symbol server downloader & parser.
- Undefine instructions after ThunRTMain in VB executables.
- Adjusted confidence levels for RTTI and EH.

### Commands
- Reworked COFF plugin.
- Experimental `mcp` plugin.

### KB
- Android definitions.
- `comctl32.dll` ordinals.
- GameBoy, GameBoy Color and GameBoy Advance definitions.
- PSX GTE functions.
- **BREAKING**: reorganized `libc` layout.

### Workspace
- Official MacOS support.
- Unified plugin dependency management with `redasm_add_dependency`.
- Implemented dependency depot and offline-only dependency management.
- AppImage now is built against Ubuntu 22.04.
